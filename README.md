# AI口播工作台 · 使用说明

为你一个人服务的本地资讯工作台：每天抓取 AI 资讯与科技热点 → AI 聚合出"今日必做"选题 → 一键生成口播稿、分镜字幕、配图、发布文案。拍摄剪辑在剪映完成。

## 快速开始

1. **双击 `启动.bat`** —— 首次运行会自动创建虚拟环境并装依赖，然后自动打开浏览器 `http://127.0.0.1:8787`
2. 按**首页三步引导**：设置页粘贴智谱 API key → 保存 → 点「测试连接」确认可用
3. 回首页点右上角**「刷新」**，等它抓完（约 1~2 分钟）
4. 看**「今日必做」**，点「做这条」→ 生成素材包 → 复制口播稿、下载配图，去拍视频

> 依赖：Windows + Python 3.11+（启动脚本自动装）；构建过前端无需 Node。若提示"前端尚未构建"，双击 `build.bat`（需 Node.js）。

## 每天怎么用（建议节奏）

- **早上**：打开 → 刷新 → 3 分钟扫完「资讯流水」→ 看首页必做，没好选题就直说（不硬凑）
- **拍到素材包**：工作台三档口播稿（15s/30s/60s）+ 分镜字幕（金色=建议上屏的金句）+ 配图（文字卡片或原文图）+ 发布文案（标题/标签/封面字）+ 风险词标注。黄字高亮的是建议替换的表述
- **拍完**：工作台点「标为已拍 ✅」，讲过的选题不会重复硬推，后续进展会标「📌续集」
- **模仿别人**：拆解库粘贴一篇喜欢的口播文案 → AI 拆五件套存为模板 → 生成素材包时选该模板套结构（只学骨架，自动查重防照搬）

## 数据与备份

- 全部数据在本机 `data/` 目录（单文件 SQLite + 配置 + 图片缓存），无云端
- **每次启动自动备份**，滚动保留最近 7 份（`data/backups/`）
- 设置页可手动**导出备份（zip）**、**导入恢复**（恢复前自动再备份一次）、**清空全部数据**（二次确认 + 强制备份）
- API key 只存本机 `data/config.json`，不会发送到智谱以外的服务

## 常见问题

- **提示"尚未配置 API key"**：去设置页粘贴智谱 key（bigmodel 开放平台获取）
- **刷新后没新内容**：资讯按 URL 和标题去重，同一天重复刷新只会有增量
- **热点聚合失败**：看 toast 报错；一般是 key 欠费或网络问题，修复后再点刷新
- **想重新评估今日选题**：首页右上「重新评估一次」
