# AI口播工作台 · 页面结构与交互设计（v1）

> 定位：本机单用户网页版。五个页面 + 一套全局交互。
> 核心流程：打开首页看「今日必做」→ 进工作台生成素材包 → 复制去拍视频。

---

## 一、信息架构

```
顶部导航（全局固定）
┌────────────────────────────────────────────────┐
│ 🎙 AI口播工作台  [今日][热点][资讯][拆解库][设置]    │
└────────────────────────────────────────────────┘

今日  /            首页：今日必做选题 + 备选 + 今日动态摘要
热点  /hotspots    热点选题库（列表）→ 点进去 = 工作台（详情）
资讯  /feed        每日资讯流水（扫读、筛选、收藏）
拆解库 /styles     他人口播文案的拆解与风格模板管理
设置  /settings    API key、抓取源开关、写稿偏好
```

- 素材包不单独占导航位，它就是「热点详情页」，从首页必做卡或热点列表进入。
- 全局右上角常驻：**上次更新时间 + 刷新按钮**（任何页面都能触发抓取）。

## 二、页面设计

### 页面1：今日（首页）

```
┌──────────────────────────────────────────────────────┐
│ 2026年10月3日 周六          上次更新 08:30  [⟳ 刷新]     │
│                                                      │
│ 📌 今日必做 (2)                                        │
│ ┌────────────────────┐  ┌────────────────────┐       │
│ │ ▓▓▓封面图▓▓▓        │  │ ▓▓▓封面图▓▓▓        │       │
│ │ GPT-5.5 正式发布     │  │ xxAI产品爆火        │       │
│ │ 为什么值得讲：…      │  │ 为什么值得讲：…      │       │
│ │ ✓3个独立来源确认     │  │ ✓2个独立来源确认     │       │
│ │ 建议时长 30s        │  │ 建议时长 60s        │       │
│ │ [做这条 →]          │  │ [做这条 →]          │       │
│ └────────────────────┘  └────────────────────┘       │
│                                                      │
│ ▸ 备选选题 (3)                          [折叠/展开]    │
│   ┌ 小卡：标题 · 热度分 · 一句角度 · [做这条] ┐          │
│   └ … … … … … … … … … … … … … … … ┘          │
│                                                      │
│ 今日动态：抓取 47 条 → 去重后 32 条 → 5 个热点          │
│ [去资讯流水看看 →]                                     │
└──────────────────────────────────────────────────────┘
```

**本页专属交互**
- 必做卡 = 热点卡片的浓缩版，点「做这条」直达工作台。
- 「今日动态」一行字讲清今天的抓取漏斗（抓了多少→剩多少→几个热点），让"宁缺毋滥"可感知。
- 备选选题默认折叠：分数够不上必做、但可以做备胎的 2~4 条。

**空状态（重要的设计点）**
- 今天没有值得做的：大卡片明说「AI 看完今天全部 32 条资讯，没有值得单独开一条视频的。理由：……」+ 按钮「重新评估一次」「去资讯流水逛逛」。**不硬凑数量。**
- 首次使用（未配 key）：全屏引导卡「3 步开始：① 去设置填智谱 key → ② 点刷新 → ③ 回来看今日必做」。

### 页面2：热点（选题库）

```
┌──────────────────────────────────────────────────────┐
│ 热点选题                                               │
│ 状态:[全部 | 待处理 | 已出素材 | 已拍]   日期:[今天 ▾]    │
│                                                      │
│ ── 10月3日 ──────────────────────────────────────     │
│ ● GPT-5.5 正式发布            热度95 · ✓3来源          │
│   大模型·产品发布   状态: 已拍 ✅        [查看]          │
│ ○ xx模型开源               热度81 · ✓2来源             │
│   大模型·开源        状态: 待处理      [做这条 →]       │
│ ── 10月2日 ──────────────────────────────────────     │
│ ✔ …历史选题（灰显，点开可回看素材包）…                    │
└──────────────────────────────────────────────────────┘
```

**本页专属交互（选题状态流，这是"主编"场景的核心）**
- 每个热点是一条**有状态的选题卡**，不是普通资讯行：
  `待处理 → 已出素材 → 已拍`，颜色区分（灰/蓝/绿）。
- 状态随动作自动流转：点「做这条」生成素材包 → 自动变"已出素材"；在工作台点「标为已拍」→ 变"已拍"。
- 同一事件的多篇报道**合并为一张卡**，卡上标「✓N个独立来源确认」（N≥2 才显示，越多越可信）。
- **打分参考你的选题历史**：讲过的方向不重复硬推；同一事件的后续进展标「📌 可做续集」，并关联往期热点卡。
- 历史选题按日期折叠保留，可回看当时生成的素材包（轻量选题库）。

### 页面3：热点详情 = 素材工作台（核心页面）

```
┌──────────────────────────────────────────────────────┐
│ ← 返回热点列表                                          │
│ ┌──────────────────┬─────────────────────────────┐   │
│ │ 【事件区】         │ 【素材区】                     │   │
│ │ GPT-5.5 正式发布   │ 档位: [15s|30s|60s] ↑默认建议  │   │
│ │                   │ 风格: [默认人设 ▾ | 拆解模板…]  │   │
│ │ 为什么值得讲        │ ┌───────────┬─────────────┐  │   │
│ │  ·…               │ │ 口播稿      │ 分镜字幕      │  │   │
│ │                   │ │ (随档位切换) │ (随档位联动)  │  │   │
│ │ 事件梳理(时间线)    │ │ 全文…       │ 0-3s 钩子:…  │  │   │
│ │  · 昨晚 官宣…      │ │            │ 3-15s 要点:… │  │   │
│ │  · 今晨 各家跟进…   │ │ [复制]      │ [复制]       │  │   │
│ │                   │ │ [重新生成]  │              │  │   │
│ │ 来源(3) ✓交叉确认  │ └───────────┴─────────────┘  │   │
│ │  · 官方X ↗ (英文)  │                              │   │
│ │  · 机器之心 ↗      │ 【配图区】选用 1-2 张           │   │
│ │  · 量子位 ↗        │ [✓原图1] [✓卡片图] [原图2] …   │   │
│ │                   │ （点缩略图预览大图，可勾选/换）    │   │
│ │ 切入角度建议        │                              │   │
│ │  · 从"免费"角度讲…  │ [⬇ 下载选中配图]               │   │
│ │                   │                              │   │
│ │ 建议时长: 30s      │ 【发布文案】标题×3·话题标签     │   │
│ │                   │ ·封面大字建议  [复制]           │   │
│ │ [生成素材包]       │ 【安全检查】⚠ 2处风险词已高亮    │   │
│ │ 📌续集标记(若讲过)  │ [复制整包]  [标为已拍 ✅]        │   │
│ └──────────────────┴─────────────────────────────┘   │
└──────────────────────────────────────────────────────┘
```

**本页专属交互**
- **一次生成整套素材包**：点「生成素材包」→ AI 一次性产出三档口播稿 + 三档分镜字幕 + 配图与默认选用 + 发布文案（标题×3、话题标签、封面大字）+ 审核安全检查，约 20~40 秒，期间右栏显示进度动画，可以去逛别的页面，生成完 toast 提醒。
- **档位切换联动**：顶部 [15s|30s|60s] 同时切换口播稿和对应分镜字幕，默认定位在 AI 建议档位。
- **风格模板**：生成前可选「拆解库」里的模板，AI 按其结构和节奏写稿（仍是你的语气人设），口播稿标注"套用了XX模板"；不选则用默认人设风格。
- **重新生成**：覆盖当前版本（v1 不保留历史版本，避免复杂；后续可加版本切换）。
- **配图区**：展示候选图 = 原文抓到的图 + 自动生成的文字要点卡片；点缩略图看大图，勾选 1~2 张为"选用"，可一键下载选中图（拷去剪映）。
- **安全检查**：口播稿生成时同步做发布风险检查——「最/第一/秒杀」等绝对化用语、医疗财经敏感表述黄字高亮，点击看替换建议；素材包附「发布前自查清单」。
- **金句标注**：分镜字幕里最值得上屏的 2~3 个数字/金句自动加粗，做字幕卡、封面直接抄。
- **续集联动**：若该事件你讲过，事件区显示「📌 你X天前讲过，可做续集」，口播稿开头自动带一句"上回说到…"衔接。
- **复制整包**：按"口播稿 + 字幕 + 配图说明 + 发布文案"的格式复制成一段文本，方便贴到备忘录/剪映。
- 素材未生成时右栏为引导态：「还没生成素材包，点左侧按钮，约半分钟」。

### 页面4：资讯（每日流水）

```
┌──────────────────────────────────────────────────────┐
│ 资讯流水                              [全部标为已读]     │
│ 搜索 [______________]                                  │
│ 分类:[全部|大模型|AI产品|科技大事件]                       │
│ 来源:[全部|官方|中文媒体|海外|热榜]   ☑只看未读  ☆收藏     │
│                                                      │
│ ┌────────────────────────────────────────────────┐  │
│ │ ● OpenAI 官宣 GPT-5.5 发布…      官方·X  09:41   │  │
│ │   AI摘要一句话……                                 │  │
│ │   ☆收藏   ↗跳原文   ·属于热点卡「GPT-5.5发布」→    │  │
│ ├────────────────────────────────────────────────┤  │
│ │ ○ 量子位：GPT-5.5 全方位评测…     媒体    10:12   │  │
│ │   （已读，灰显）                                  │  │
│ └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

**本页专属交互（扫读场景）**
- 条目 = 一行摘要 + 来源徽章（官方/媒体/海外/热榜）+ 时间；点条目**原地展开**完整摘要和操作，不跳页。
- **点开即已读**（灰显）；「只看未读」一键过滤；「全部标为已读」一键清场。
- 收藏☆ = 选题备用箱；海外源条目自动带中文翻译摘要，跳原文看英文。
- 同事件条目挂了热点卡的，显示「·属于热点卡 →」可跳转，避免在流水里重复看。
- 搜索：按关键词过滤今天的/历史的资讯。

### 页面5：拆解库（风格模板）

```
┌──────────────────────────────────────────────────────┐
│ 拆解库                                [+ 拆解一篇口播]  │
│                                                      │
│ ┌────────────────────────────────────────────────┐  │
│ │ 模板A ·「XX的悬念式开头」             10月2日     │  │
│ │ 钩子:反问悬念 · 结构:钩子→反转→数据→升华(4段)     │  │
│ │ 已用2次 · [查看] [套用写一条] [编辑] [删除]        │  │
│ ├────────────────────────────────────────────────┤  │
│ │ 模板B ·「数据轰炸型」                 9月28日     │  │
│ │ …                                               │  │
│ └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

**本页专属交互**
- 「+ 拆解一篇口播」→ 弹窗粘贴文案文本 → AI 拆解 → 预览确认后保存为模板（v1 用粘贴；v1.5 起同一入口也支持直接丢抖音链接自动转写）。
- **AI 拆解产出五件套**：① 钩子类型（悬念反问/数字冲击/反常识…）② 段落结构骨架（每段标功能，如"第1段抛冲突"）③ 节奏特征（句长、换行密度、口头禅）④ 金句模式 ⑤ 结尾 CTA 类型。
- 保存时可命名；拆得不准可直接编辑；删除需二次确认。
- 「套用写一条」= 选一个今日热点，跳工作台并预选该模板。
- **边界**：拆解学的是结构和节奏，不是照搬文案；生成时仍用你自己的"轻松接地气"人设改写，避免同质化。

## 三、全局交互规则

| 场景 | 行为 |
|---|---|
| 刷新（全局按钮） | 抓取→翻译→AI摘要→去重→热点聚合打分，整条流水线一次跑完；按钮变进度态「抓取中 3/6 源…」；完成后 toast「新增 12 条，1 个新热点」 |
| 源失败 | 单个源失败不影响其他源；刷新结果里红字提示「机器之心失败 [重试]」 |
| AI 调用失败 | key 无效/欠费时明确报错并引导去设置页 |
| 加载/生成中 | 统一骨架屏 + 进度文案；生成素材包可离开页面，完成后 toast |
| 自动归档 | 首页必做只显示今天；昨天及以前的选题进热点库按日期折叠 |

## 四、数据与状态（模块如何咬合）

```
资讯条目(item)          热点卡(hotspot)           素材包(pack)
- 标题/摘要/原文链接  ──→  - 事件标题/梳理/角度    ──→  - 三档口播稿(风险词标注)
- 来源(官方/媒体/榜单)    - 来源聚合 + 交叉确认数       - 三档分镜字幕(金句加粗)
- 分类/已读/收藏      ←─  - 热度分/建议时长/状态     - 选用配图
- 状态: 未读/已读/收藏    待处理→已出素材→已拍          - 发布文案(标题/标签/封面字)
     ↑打分参考选题历史        +续集标记(讲过的事件)      - 发布前自查清单

风格模板(style)：从他人口播文案拆解（钩子/结构/节奏/金句/CTA），生成素材包时可选用套结构，记录已用次数。
```

- 同事件多条资讯通过事件 ID 挂到同一张热点卡（去重的上游逻辑）。
- 素材包属于热点卡；资讯的「收藏」是轻量标记，热点卡才是正式选题。
- 全部数据存本机 SQLite，无需登录。

## 五、v1 明确不做（交互层面）

- 深色模式、手机端适配（桌面浏览器优先，宽度自适应但不专门做移动布局）
- 素材包历史版本、多方案对比
- 定时自动抓取、推送通知
- 键盘快捷键、批量操作

## 六、后续版本规划

- **v1.5**：蹲点日历——首页预告「近期值得蹲的事件」（发布会、政策节点），提前备稿；抖音链接自动转写——拆解库同一入口支持直接丢视频链接（自动下载→语音转文字→填入拆解）。
- **v2**：效果回流（手动记录播放/点赞，按你账号的实际数据优化打分和角度建议）。
